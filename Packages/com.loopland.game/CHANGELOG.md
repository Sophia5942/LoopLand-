# Changelog

## 1.1.0
- Drink machine: a networked soda fountain built from Drink_Machine_1 (LoopLand > Build Drink Machine In Scene).
  Cups lock into the machine when you set them down, each nozzle has a world-space push-button panel (laser, mouse and
  VR finger presses with haptics), pours fill the cup with a rising-pitch pour loop, fizz, slurp and lock sounds,
  drinks mix by flavor, and cups respawn (button, idle / empty timers, falling out of the world, auto-restock).
  Bandwidth-light manual sync: nothing is sent while nothing changes. Quest-friendly shaders.

## 1.0.0
- First release: networked LoopLand board game (2-6 players), particle tokens, animated 3D dice,
  persistent Loop Coins, cosmetics store, VRChat Creator Economy integration, one-click scene builder.
