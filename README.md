# LoopLand

A premium Monopoly-style board game package for VRChat worlds (Creator Companion / Worlds SDK 3.8.1+),
with particle tokens, animated dice, persistent Loop Coins, an in-game store and VRChat Creator Economy integration.

The package lives in [`Packages/com.loopland.game`](Packages/com.loopland.game). Start with its
[README](Packages/com.loopland.game/README.md) for install, one-click build and store setup.

It also includes a networked **drink machine** (soda fountain with cup locking, push-button UI, VR finger presses and
cup respawn): **LoopLand > Build Drink Machine In Scene**. See the package README.
